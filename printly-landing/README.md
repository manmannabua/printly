# Printly Landing

Static landing page for Printly, separate from the Laravel API and Vue app.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Content Model

The page is based on the current Printly product surface:

- Public storefronts for file upload, quoting, checkout, and QR tracking.
- Store queue board with order statuses and customer chat.
- Catalog and pricing rules for file-based and spec-based products.
- PayMongo payments, cash-on-pickup, subscriptions, and optional auto-print.

The generated hero image lives at `public/assets/printly-hero.png`.
